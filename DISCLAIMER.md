# Disclaimer

This repository is a demonstration and educational proof of concept. It is not a production-ready application, deployment reference, security baseline, compliance implementation, or supported product.

## Preview software

Box Mount is preview software. Access, behavior, limitations, and availability may change. The Box Mount binary is not included in this repository and must be obtained through the applicable Box preview process.

## Security and privacy

The examples simplify identity, secret management, networking, observability, error handling, and resource controls for demonstration purposes. Do not use real resumes, personal data, confidential content, production credentials, or enterprise-wide Box access with the sample without a separate security and privacy review.

Use a dedicated Box application, a narrowly scoped Box identity, a disposable Box folder, and temporary Google Cloud resources. Review the deployment before adapting it to any production workload.

## CV review limitations

The CV workflow is an assistive document-review example only. It must not make or automate employment decisions, infer protected characteristics, or replace qualified human review. The included documents are fictional.
