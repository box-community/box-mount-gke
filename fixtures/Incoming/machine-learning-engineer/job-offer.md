# Machine Learning Engineer

> Fictional demo offer. Meridian Analytics is invented.

## Role

Build language and prediction features for an enterprise analytics product.

## Responsibilities

- Develop and evaluate machine learning models in Python.
- Build natural language processing (NLP) and retrieval workflows.
- Create reliable data pipelines using SQL and cloud services.
- Package models with Docker and deploy services on GCP.
- Track experiments, model quality, and production behavior.
- Explain technical tradeoffs to product and engineering partners.

## Required experience

- Three or more years of professional machine learning experience.
- Strong Python and SQL skills.
- Experience with NLP, model evaluation, and data preparation.
- Experience deploying production services with Docker.
- Familiarity with GCP and software engineering practices.

## Helpful experience

- Kubernetes and model serving.
- Large language models and prompt evaluation.
- Feature stores, experiment tracking, or data quality monitoring.
